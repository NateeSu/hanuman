# Gameplay Objects and VFX

4×2 chroma-key atlas: golden Rama seal, cyan-gold checkpoint shrine, cracked dash wall, violet sleep-mist urn, green-gold heart reliquary with bee, poisonous heart seal, crimson ornamental blade, black-gold exit portal. Crisp painterly game props, full object visible, no labels or shadows.

Wind, melee impact, dissolve and warning effects are rendered procedurally in Phaser using the same cyan/gold/violet palette.
